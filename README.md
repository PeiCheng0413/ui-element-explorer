# 元件圖鑑 UI Element Field Guide

滑鼠移到網頁的任何一個地方，它會告訴你那塊東西叫什麼——中文名、英文名，還有一句可以直接貼給 AI 的描述。

給那些會用 AI 做網站、但講不出「header」「placeholder」「modal」的人。

**線上版：** https://peicheng0413.github.io/ui-element-explorer/

---

## 這個網站在做什麼

跟 AI 說「上面那個東西怪怪的」，AI 只能猜。說「頁首（header）裡的主要按鈕（primary button）圓角改成 8px」，一次就改對。

差別只在於知不知道那個東西的名字。這頁把 52 個常見的介面元件放進一個真的會動的示範網站裡，讓你用滑鼠指過去就學會。

## 怎麼用

1. **探索模式**（預設）：滑鼠移到示範網站的任何地方，旁邊會拉出一條引線和標籤，寫著這個元件的中英文名稱。手機請用點的。
2. **點一下**任何元件，右下角會展開完整說明：用途、它在版面裡的位置階層、中文與英文關鍵字、一句寫好的 AI 提示語，以及「也有人叫它什麼」。
3. **圖鑑目錄**可以搜尋。用口語也找得到——搜「灰色的字」會找到提示文字 placeholder，搜「跳出來的視窗」會找到 modal。
4. **體驗模式**把標註關掉，示範網站就恢復正常操作，按鈕、表單、彈出視窗都會真的動。

## 收錄的元件

52 個，分成五類：

| 類別 | 內容 |
| --- | --- |
| 版面結構 | 頁首、頁尾、主視覺區、卡片、網格、側邊欄、內容容器、分隔線、網站標誌 |
| 導覽 | 導覽列、導覽連結、下拉選單、麵包屑、分頁標籤、分頁導覽、漢堡選單鈕 |
| 輸入控制 | 表單、欄位標籤、單行／多行輸入框、提示文字、下拉式選單、核取方塊、單選鈕、開關、滑桿、搜尋框、按鈕、說明文字 |
| 回饋提示 | 彈出視窗、遮罩、浮動通知、提示氣泡、通知橫幅、進度條、載入圖示、狀態標記、錯誤訊息 |
| 內容呈現 | 標題、段落、眉標、清單、表格、折疊面板、標籤片、數據區塊、頭像、縮圖、圖示、文字連結 |

## 技術

沒有框架、沒有建置流程，三個檔案就是全部：

```
index.html      示範網站與圖鑑頁面
css/styles.css  樣式
js/data.js      52 個元件的資料
js/app.js       標註、引線、目錄、模式切換
```

需要新增元件時，在 `js/data.js` 加一筆，並在 `index.html` 對應的節點加上 `data-el="你的 id"` 即可。載入時會自動比對，資料與畫面對不起來會在瀏覽器主控台提出警告。

示範網站的內容（順風號海釣船）為虛構，僅供教學使用。
